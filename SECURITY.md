# Security Policy

## Supported Versions

We currently provide security updates and support for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within the GMWF application, please do not disclose the information publicly.

Instead, please report it immediately to the administrative or development team. We take all security vulnerabilities seriously and will work to address them as quickly and efficiently as possible. When reporting an issue, please include detailed steps to reproduce the vulnerability.
